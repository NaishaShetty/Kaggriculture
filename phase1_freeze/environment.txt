INSTALLATION PROCEDURE (reproduce from scratch)
  1. python -m venv C:\kagvenv
     — MUST be a short base path. Installing into the default global site-packages
       (AppData\Local\...\Python311\Lib\site-packages) or --user site-packages
       (AppData\Roaming\...\Python311\site-packages) both fail with Windows MAX_PATH errors while
       unpacking `orbax-checkpoint`'s deeply-nested bundled test-fixture files (observed errors:
       "WinError 32: file in use" / "WinError 206: filename too long" / "No such file or directory"
       depending on exact path depth at the time). A short venv base (C:\kagvenv) was the workaround
       that let installation complete; it may still fail on installs deep enough into the dependency
       tree, which is why step 3 below deliberately avoids that tree.
  2. C:\kagvenv\Scripts\python.exe -m pip install --no-deps kaggle-environments
     — installs the kaggriculture package itself without pulling in its full dependency graph,
       sidestepping the problematic resolution order.
  3. C:\kagvenv\Scripts\python.exe -m pip install Flask jsonschema numpy pygame pyjson5 termcolor \
       requests tenacity google-auth pydantic kaggle
     — installs everything kaggle_environments actually imports at module-load time for the
       kaggriculture environment specifically.
  4. INTENTIONALLY OMITTED: gymnax, flax, orbax-checkpoint, optax, chex, litellm, transformers.
     These are declared as hard Requires-Dist by kaggle-environments 1.32.7 (it bundles many
     environments in one package, including RL/LLM environments that need this stack), but
     `kaggriculture.py` itself does not import any of them — confirmed by `import kaggle_environments`
     succeeding and the full kaggriculture smoke test / all Phase 1 experiments running without error.
     `jax` (0.10.2) ended up installed anyway as an incidental transitive dependency pulled in while
     resolving other packages in step 3 — it has no bundled test-fixture long-path problem on its own
     and caused no issues, so it was left in place rather than surgically removed.
  5. Kaggle auth: API token saved to ~/.kaggle/access_token (chmod 600), obtained from
     kaggle.com/settings/api. Verified via `kaggle competitions list -s kaggriculture` and
     `kaggle competitions list --group entered`.
